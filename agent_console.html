🧠 Google Cloud 3-Tier Agent Memory Architecture Sub-Millisecond Working Memory

GCP replaces standalone Redis memory layers with native Cloud Memorystore for Redis (working session context & semantic cache) alongside Cloud Firestore (distributed state locks) and Vertex AI Vector Search (long-term semantic retrieval).

1. Short-Term / Working Memory
Cloud Memorystore for Redis · Sub-1ms agent-to-agent session state & prompt semantic cache.
2. Transactional State Memory
Cloud Firestore · Persistent document state, order traces, and concurrency locks.
3. Long-Term Knowledge Memory
Vertex AI Vector Search · 768-dim embeddings over regulatory SOPs & compliance corpus.
